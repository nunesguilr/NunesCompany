# 12 · Química Orgânica

**Resumo:** características do carbono, cadeias carbônicas, funções orgânicas, nomenclatura IUPAC, isomeria e reações típicas.

## O carbono (postulados de Kekulé)

1. **Tetravalência:** faz sempre 4 ligações.
2. Ligações entre carbonos podem ser simples, duplas ou triplas.
3. Encadeamento: forma cadeias longas e variadas.

- Tipos de carbono: **primário** (ligado a 1 C), **secundário** (2), **terciário** (3), **quaternário** (4).
- Hibridação: **sp³** (4 ligações simples, tetraédrica ~109,5°), **sp²** (1 dupla + 2 simples, trigonal plana 120°), **sp** (1 tripla ou 2 duplas, linear 180°).

## Cadeias carbônicas

- **Aberta (acíclica) / fechada (cíclica).**
- **Normal** (2 extremidades) / **ramificada** (≥ 3 extremidades).
- **Saturada** (só ligações simples) / **insaturada** (dupla ou tripla).
- **Homogênea** (só C) / **heterogênea** (heteroátomo O, N ou S entre carbonos).
- **Aromática:** contém anel benzênico (6 elétrons π deslocalizados).

## Funções orgânicas principais

| Função | Grupo característico | Exemplo |
|---|---|---|
| Hidrocarboneto (alcano) | só C e H, ligações simples | CH₄ metano, C₃H₈ propano |
| Alceno | C=C | C₂H₄ eteno (etileno) |
| Alcino | C≡C | C₂H₂ etino (acetileno) |
| Alcadieno | duas C=C | C₄H₆ buta-1,3-dieno |
| Aromático | anel benzênico | C₆H₆ benzeno, tolueno, naftaleno |
| Álcool | –OH em C saturado | CH₃CH₂OH etanol |
| Fenol | –OH direto no anel aromático | C₆H₅OH fenol |
| Enol | –OH em C com dupla | CH₂=CHOH (instável) |
| Éter | C–O–C | CH₃–O–CH₃ metóxi-metano |
| Aldeído | –CHO (carbonila na ponta) | HCHO metanal (formol) |
| Cetona | C=O entre carbonos | CH₃COCH₃ propanona (acetona) |
| Ácido carboxílico | –COOH | CH₃COOH ácido etanoico (acético) |
| Éster | –COO– | CH₃COOCH₂CH₃ etanoato de etila |
| Amina | derivada de NH₃ (–NH₂, –NHR, –NR₂) | CH₃NH₂ metilamina |
| Amida | –CO–N< | ureia, etanamida |
| Haleto orgânico | C–X (F, Cl, Br, I) | CH₃Cl clorometano |
| Nitrila | –C≡N | CH₃CN etanonitrila |

## Nomenclatura IUPAC

**Prefixo (nº de C) + infixo (ligações) + sufixo (função)**

| C | Prefixo | Ligação | Infixo | Função | Sufixo |
|---|---|---|---|---|---|
| 1 | met- | só simples | -an- | hidrocarboneto | -o |
| 2 | et- | uma dupla | -en- | álcool | -ol |
| 3 | prop- | uma tripla | -in- | aldeído | -al |
| 4 | but- | duas duplas | -dien- | cetona | -ona |
| 5 | pent- | | | ácido carboxílico | ácido …-oico |
| 6 | hex- | | | amina | -amina |
| 7 | hept- | | | | |
| 8 | oct- | | | | |

- Numere a cadeia principal dando os **menores números** às insaturações; depois às ramificações.
- Ramificações: metil-, etil-, propil-… em ordem alfabética (di-, tri- não contam).
- Ex.: CH₃–CH(CH₃)–CH=CH₂ → 3-metilbut-1-eno.

## Isomeria

### Plana (mesma fórmula molecular, fórmulas estruturais diferentes)

- **De cadeia:** butano × 2-metilpropano (C₄H₁₀).
- **De posição:** but-1-eno × but-2-eno; propan-1-ol × propan-2-ol.
- **De função (metameria funcional):** etanol (álcool) × metóxi-metano (éter) — ambos C₂H₆O; propanal × propanona (C₃H₆O).
- **De compensação (metameria):** posição do heteroátomo — CH₃–O–CH₂CH₂CH₃ × CH₃CH₂–O–CH₂CH₃.
- **Tautomeria (dinâmica):** equilíbrio entre isômeros, ex.: aldeído ⇌ enol; cetona ⇌ enol.

### Espacial (diferença no arranjo no espaço)

- **Geométrica (cis–trans / E–Z):** requer dupla ligação ou ciclo + grupos diferentes nos carbonos da dupla.
  - *cis*: grupos iguais do mesmo lado; *trans*: lados opostos. Ex.: cis-but-2-eno × trans-but-2-eno.
- **Óptica:** presença de **carbono quiral** (4 ligantes diferentes).
  - Enantiômeros: imagens especulares não sobreponíveis; desviam a luz polarizada para a direita (**dextrogiro, +**) ou esquerda (**levogiro, −**).
  - Mistura racêmica: 50/50, não desvia a luz. Ex.: ácido lático, aminoácidos.

## Reações orgânicas (visão geral)

- **Substituição:** típica de alcanos (halogenação com luz/UV) e aromáticos (nitração, sulfonação, halogenação, alquilação).
- **Adição:** em alcenos/alcinos — hidrogenação (H₂/Ni), halogenação (Br₂/CCl₄, teste da dupla), adição de HX (**regra de Markovnikov: o H vai para o C mais hidrogenado**), hidratação.
- **Eliminação:** desidratação intramolecular de álcoois → alceno (H₂SO₄, calor); eliminação de HX de haletos.
- **Oxidação:** álcool 1º → aldeído → ácido carboxílico; álcool 2º → cetona; álcool 3º não oxida em condições brandas. KMnO₄ e K₂Cr₂O₇ são oxidantes clássicos.
- **Esterificação (Fischer):** ácido + álcool ⇌ éster + água; a inversa é a **hidrólise**.
- **Saponificação:** éster (gordura) + base forte → sabão (sal de ácido graxo) + glicerol.

## Polímeros (visão geral)

- **De adição:** polietileno (eteno), PVC (cloreto de vinila), poliestireno, PTFE/teflon (tetrafluoreteno), polipropileno.
- **De condensação:** náilon (poliamida), PET (poliéster), baquelite — liberam moléculas pequenas (H₂O, HCl).
- **Naturais:** celulose e amido (glicose), proteínas (aminoácidos), borracha natural (isopreno), DNA.

## Macetes

- Fórmulas gerais: alcanos **CₙH₂ₙ₊₂**; alcenos e ciclanos **CₙH₂ₙ**; alcinos e alcadienos **CₙH₂ₙ₋₂**.
- "Álcool primário vira aldeído; secundário vira cetona; terciário não oxida."
- Markovnikov: na adição de HX, **H para o mais rico em H** (e X para o C mais substituído).
- Fenol não é álcool: o –OH está no anel aromático (caráter levemente ácido).
- Éster = gordura/óleo; amida = proteína; glicosídeo = carboidrato.
