# 09 · Termoquímica

**Resumo:** reações exo e endotérmicas, entalpia, equação termoquímica, Lei de Hess e energia de ligação.

## Reações térmicas

- **Exotérmica:** libera calor; ΔH < 0; os produtos têm **menos** energia que os reagentes.
  - Ex.: combustões, neutralizações, condensação, solidificação.
- **Endotérmica:** absorve calor; ΔH > 0; os produtos têm **mais** energia que os reagentes.
  - Ex.: fotossíntese, decomposição do CaCO₃, fusão e vaporização.

## Entalpia (H)

ΔH = H_produtos − H_reagentes (a pressão constante)

- ΔH < 0 → exotérmica; ΔH > 0 → endotérmica.
- Não se mede H absoluta — só a **variação** ΔH (em kJ ou kJ/mol).

## Equação termoquímica

Deve indicar estados físicos, condições e o ΔH:

H₂(g) + ½ O₂(g) → H₂O(l) ΔH = −286 kJ/mol

Regras de manipulação:
- **Inverter** a reação → **inverte o sinal** de ΔH.
- **Multiplicar** coeficientes por n → **multiplica** ΔH por n.
- Estados físicos importam: H₂O(g) é mais energético que H₂O(l) (diferença = calor de vaporização).
- Formas alotrópicas importam: C(grafite) é a forma estável (ΔH_f° = 0), não o diamante.

## Lei de Hess

O ΔH de uma reação depende **apenas dos estados inicial e final**, não do caminho — some os ΔH das etapas (ajustando sinais e coeficientes).

Exemplo (combustão do carbono via CO):

1. C(s) + ½ O₂(g) → CO(g) ΔH₁ = −110,5 kJ
2. CO(g) + ½ O₂(g) → CO₂(g) ΔH₂ = −283,0 kJ

Soma: C(s) + O₂(g) → CO₂(g) ΔH = **−393,5 kJ**

## Entalpia de formação

ΔH_f°: variação de entalpia na formação de **1 mol** da substância a partir dos elementos no estado padrão.

- Elemento no estado padrão tem **ΔH_f° = 0** (O₂(g), C(grafite), Fe(s)…).
- Cálculo pela entalpia de formação: **ΔH_reação = Σ ΔH_f°(produtos) − Σ ΔH_f°(reagentes)**, respeitando os coeficientes.

## Energia de ligação

- **Quebrar** ligação → **absorve** energia (+).
- **Formar** ligação → **libera** energia (−).

ΔH = Σ E(ligações quebradas) − Σ E(ligações formadas)

Valores típicos (kJ/mol): H—H 436; O=O 498; O—H 463; C—H 413; C=O (no CO₂) 805; C=C 614; N≡N 946.

Ex.: H₂(g) + ½ O₂(g) → H₂O(g)
- Quebra: 436 + ½·498 = 685 kJ
- Forma: 2 × 463 = 926 kJ
- ΔH = 685 − 926 = **−241 kJ/mol** (água no estado gasoso).

## Macetes

- "**EXO**sai" (calor sai, ΔH negativo); "**ENDO**entra" (calor entra, ΔH positivo).
- Combustão completa de hidrocarbonetos → sempre **CO₂ + H₂O** (e ΔH < 0).
- Na Lei de Hess: trate as equações como álgebra — some, inverta e multiplique.
