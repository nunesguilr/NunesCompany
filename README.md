## 🧭 Como usar

- Cada arquivo é independente e segue o mesmo formato: **resumo → tópicos → exemplos → macetes**.
- Ideal para revisão rápida antes de provas e simulados.
- Sugestão de ordem de estudo: 01 → 12 (os assuntos são progressivos).
